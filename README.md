# 표현의 벽 (expression-wall)

관람객이 단어·문구를 적어 벽에 붙이고, 이미 걸린 단어와 **빨간 실**로 이어 가는 전시용 웹페이지.
한 달간 전시장 키오스크 1대에서 돌아가는 것을 전제로 만들었다.

- 벽 화면 `/` — 관람객이 보는 화면
- 관리자 화면 `/#/admin` — 운영자가 잘못된 문구를 고치고, 선을 잇고, 기록을 내보내는 화면

## 실행

```bash
pnpm install
pnpm dev     # http://localhost:5180
pnpm build   # dist/ 로 정적 빌드
pnpm preview # 빌드 결과 확인
```

전시장에서는 `pnpm build` 후 `dist/`를 그대로 띄우고, 브라우저를 전체화면(F11)으로 둔다.

## 저장 방식

모든 기록은 **브라우저의 localStorage**에 들어간다. 서버가 없으므로 기기와 브라우저가 바뀌면
기록도 따라오지 않는다. 전시 중에는 **같은 기기, 같은 브라우저**를 계속 써야 한다.

| 키 | 내용 |
| --- | --- |
| `expression-wall:v1` | 현재 기록 (카드 · 연결 · 설정) |
| `expression-wall:v1:backup` | 덮어쓰기 직전 상태 한 세대 |
| `expression-wall:admin` | 관리자 로그인 여부 (탭을 닫으면 사라짐) |

안전장치:

- 변경이 생길 때마다 즉시 저장하고, 직전 상태를 백업 키에 한 세대 남긴다.
- 주 저장소가 깨져 읽히지 않으면 백업에서 자동으로 복구한다.
- 깨진 항목(사라진 카드로 이어진 선, 중복된 선 등)은 불러올 때 조용히 걸러 낸다.

> **하루 한 번은 관리자 → 데이터 → `JSON 내보내기`로 백업 파일을 받아 두기를 권한다.**
> 브라우저 데이터 삭제·시크릿 모드·기기 교체는 기록을 날린다.

나중에 여러 기기에서 모아야 한다면 `src/lib/store.ts`의 `commit()` 한 곳만 서버 호출로
바꾸면 된다. 화면 쪽 코드는 손대지 않아도 된다.

## 관람객 흐름

1. 아래 **내 단어 붙이기** 버튼
2. 1단계 — 단어나 문장 입력 (기본 40자 제한, 이름은 선택)
3. 2단계 — 벽에 이미 걸린 단어 중 최대 3개를 골라 연결 (건너뛰어도 됨)
4. 카드가 빈자리를 찾아 붙고, 연결된 선이 그려지는 애니메이션이 재생된다

키오스크를 염두에 둔 동작:

- 작성 창을 열어 둔 채 90초간 아무 조작이 없으면 스스로 닫힌다 (`IDLE_RESET_MS`)
- 길게 눌러 생기는 텍스트 선택·확대를 막아 두었다

## 관리자 화면

주소창에 `#/admin`을 붙이거나, 벽 화면 **오른쪽 아래 구석을 1.5초 안에 3번** 누르면 열린다.

암호는 기본 `wall2026`. 바꾸려면 프로젝트 루트에 `.env.local`을 만든다.

```
VITE_ADMIN_PASSCODE=원하는암호
```

> 이 암호는 화면을 가리는 잠금일 뿐 실제 인증이 아니다. 빌드 결과물 안에 그대로 들어가므로
> 공개망에 올린다면 중요한 암호를 쓰지 말 것.

| 탭 | 할 수 있는 일 |
| --- | --- |
| 카드 목록 | 문구·작성자 수정, 숨기기(벽에서만 감춤), 삭제, 검색 |
| 벽 배치 · 연결 | 카드를 끌어 옮기기, 두 장을 눌러 선 잇기/끊기, 자동 재배치, 연결 목록 관리 |
| 데이터 | JSON 내보내기·가져오기, 직전 상태 복원, 전체 초기화 |
| 전시 설정 | 제목·부제·질문·카드 머리말, 연결 개수/글자 수 제한, 금칙어 |

벽 화면과 관리자 화면을 다른 탭에 띄워 두면 수정이 서로 즉시 반영된다.

## 구조

```
src/
  config.ts              전시 상수(암호, 저장 키, 기본 설정)
  types.ts               카드 · 연결 · 설정 타입
  lib/
    storage.ts           localStorage 읽기/쓰기, 손상 데이터 복구
    store.ts             전역 상태 + 모든 변경 동작 (useSyncExternalStore)
    wall.ts              빈자리 찾기, 재배치, 금칙어 검사
  components/
    WallCanvas.tsx       카드 위치 측정 · 드래그 · 실 레이어 조립
    CardNote.tsx         포스트잇 한 장
    LinkLayer.tsx        카드 중심을 잇는 빨간 곡선 SVG
    ComposeModal.tsx     관람객 작성 2단계 모달
  pages/
    WallPage.tsx         벽 화면
    AdminPage.tsx        관리자 화면
```

실의 양 끝은 실제로 렌더된 카드의 중심을 직접 재서 잡는다. 글자 수에 따라 카드 높이가
달라지거나 화면 크기가 바뀌어도 선이 어긋나지 않는다.
